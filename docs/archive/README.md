# Archived project material

Files under this directory preserve superseded analyses, audits, and reports. They are
historical evidence of how the project developed, not current methods or findings.

Every newly archived workstream should include a visible header stating:

- Date archived
- Original purpose
- Last compatible data vintage
- Why it was retired or superseded
- Current replacement, if any
- Whether its outputs remain reproducible

Current interpretation lives in `../project_status.md`; current statistical and data
rules live in `../methods_reference.md`.
