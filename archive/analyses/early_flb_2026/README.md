# Archived: early broad FLB analyses

**Archived:** 2026-09-06

**Compatible period:** principally the pre-June-2026 local and EC2 data layouts

These modules cover the project's initial broad calibration, trader-characteristic, P&L,
market-accuracy, closing-price, and Manifold explorations. They were retired because the
canonical data, market spine, bot flags, and headline measurement specification changed.

The current replacement is `analysis/calibration_heterogeneity/`. No claim produced by
this directory should be treated as current without a deliberate reproduction.
